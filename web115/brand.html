Brand Guide

Brand Name

M.H. Web Design Co.

Brand Concept

M.H. Web Design Co. is a fictional web design brand focused on creating simple, clean, and functional websites. The goal of the brand is to prioritize readability, usability, and straightforward design without unnecessary visual clutter.

Tagline

"Simple. Clean. Functional."

Color Scheme

  • Page Background — #f2f0e9: Used as the main background color throughout the website. Background Example
  • Content Background — #e4e1d8: Used for the main content area. Content Example
  • Text — #292929: Used as the primary text color. Text Example
  • Accent — #345995: Used primarily for navigation and hyperlinks. Accent Example

Typography

  • Verdana: Used for headings because it provides a clear and noticeable appearance. Verdana Heading Example
  • Arial: Used for body text because it is simple and easy to read. Arial Body Text Example

Logo and Favicon

The M.H. Web Design Co. logo features a hawk along with the initials "MH" to represent the Mighty Hawk identity of the website. The logo is designed to be recognizable while maintaining a clean and professional appearance. Its transparent background allows it to work naturally with the website's background.

The favicon is a simplified version of the logo designed specifically for the small size of a browser tab. The simplified design helps keep the brand recognizable even when displayed at a very small size.

Logo: M.H. Web Design Co.

Mission Statement

The mission of M.H. Web Design Co. is to create straightforward websites that are easy to navigate, easy to read, and visually consistent. The brand emphasizes function and clarity over unnecessary complexity.
